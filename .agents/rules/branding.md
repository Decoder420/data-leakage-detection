# DecodeX Security Technologies Private Limited — Organizational Branding Rules

## 1. Ownership & Attribution
- All code, documentation, scripts, repositories, APIs, architectures, reports, and work products in this workspace belong to **DecodeX Security Technologies Private Limited**.
- Whenever generating README files, code headers, footers, docstrings, licensing text, about sections, or any branding-related content, attribute the project to **DecodeX Security Technologies Private Limited** as the owning organization.
- Never attribute to individual personal names, generic placeholders, or any third-party company names unless explicitly instructed.
- Standard Copyright Line:
  `Copyright (c) 2026 DecodeX Security Technologies Private Limited. All rights reserved.`

## 2. Official Visual Assets
Always use the official logo files stored in `assets/branding/` (and `frontend/public/branding/`):
- **Full Horizontal Logo**: `assets/branding/decodex_logo_full_horizontal.png` (Default for README headers, documentation covers, top banners)
- **Wordmark Only**: `assets/branding/decodex_wordmark.png` (For clean text-level branding)
- **Circuit Emblem / Icon Only**: `assets/branding/decodex_icon.png` (For favicons, app badges, circular/square avatars)
- **Stacked Vertical Logo**: `assets/branding/decodex_logo_stacked.png` (For splash screens, presentation title slides, center cards)

## 3. Preservation & Integrity
- Do NOT alter, recolor, distort, or redesign the logo images.
- Do NOT generate placeholder logos when these official assets are available.
